# Site perso de Simon Rabaux - Reconstruction

Site de blagues personnel récupéré depuis l'Internet Archive.

## Original URL
**http://users.skynet.be/bk337183**

Archivé entre juillet 2004 et octobre 2005.

## Ce qui a été récupéré

### ✅ Contenu complet
- **Toutes les pages HTML** avec le texte complet des blagues
- Structure de navigation originale
- Mise en page en tableaux (style années 2000)

### ✅ Images partiellement récupérées
- **10 images de navigation** sur ~17 (les autres n'étaient pas archivées)
- **3 photos de blagues** sur ~28 (chat_3.jpg, calecon_spiderman.jpg, carroserie_femme.jpg)
- Images manquantes remplacées par des placeholders gris

### 📁 Structure du site
```
/index.html           - Page d'accueil
/Pages/
  blagues.html        - Page de blagues
  blaguesperso.html   - Blagues personnelles
  photos.html         - Galerie de photos
  videos.html         - Page vidéos
/images/              - Images de navigation
/Content/             - Photos et images de contenu
```

## Technologies
- HTML 4.01 Transitional (original)
- Mise en page par tableaux
- Pas de JavaScript
- Arrière-plan GIF

## Visualisation locale

python3 -m http.server 8000
